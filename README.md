# E-Commerce Risk Analysis Using SQL

## Project Overview

This project analyzes e-commerce order data using SQL to identify customer purchasing behavior, spending patterns, and fraud risks.

## Tools Used

* MySQL
* SQL
* GitHub

## Dataset Features

* Order Information
* Country
* Device Type
* Traffic Source
* Payment Method
* Product Category
* Order Value
* Previous Orders
* Fraud Indicators
* Risk Labels

## Analysis Performed

### Data Cleaning

* Null value checks
* Duplicate order detection

### Exploratory Data Analysis

* Total orders
* Total revenue
* Average order value
* Orders by country

### Customer Segmentation

* Loyal customers
* Regular customers
* New customers

### Spending Analysis

* High-value customers
* Medium-value customers
* Low-value customers

### Fraud Analysis

* Fraud rate by product category
* Fraud by device type
* Fraud by payment method

## Key Insights

* Identified customer segments based on previous purchasing history.
* Compared spending behavior across customer groups.
* Evaluated fraud trends across product categories.
* Analyzed fraud patterns by device and payment methods.

## SQL Skills Demonstrated

* Aggregate Functions
* CASE Statements
* GROUP BY
* ORDER BY
* Data Cleaning
* Business Analysis
